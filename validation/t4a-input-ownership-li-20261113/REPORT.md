# T4a — protocol/sql 输入所有权转移（结论：不并入）

基线：T3 提交。改动：`src/protocol.cpp` 的 `request.sql = std::move(field.decoded)`；
`src/sql.cpp` 的 `literal()` 用 `std::move(t.text)` 取代拷贝。

## 实测（2 CPU cgroup，1000 次查询，12 对 × 2 轮）

| 轮次 | 写入中位 | 写入胜率 | 查询中位 | 查询胜率 |
| --- | ---: | ---: | ---: | ---: |
| 第一轮 | −1.88% | 5/12 | −5.91% | 4/12 |
| 第二轮 | +5.58% | 9/12 | −2.31% | 4/12 |

## 结论

- 写入侧方向不一致（−1.9% 与 +5.6%），属噪声。
- 查询侧两轮都是 4/12 胜、中位 −2~−6%，方向一致偏负（合计 8/24）。
  该改动理论上只会减少一次分配，不应变慢；怀疑是二进制布局效应，但**没有证据支持收益**。
- 按「稳定净收益才合入」，**不并入集成分支**，保留原始数据与本分支备查。

## 语义

测试全绿（CTest 9/9）。转移所有权的前提已核对：JSON 字段在 `parse_request` 返回后不再使用；
SQL Token 在 `literal()` 消费后不再被读取（解析器无回溯）。
