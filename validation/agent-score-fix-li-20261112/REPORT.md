## 3. 可核对的原因

公开赛题规则第 3.4.4 节规定：任一评价维度出现证据不足，分数为 `null`，状态为 `NEEDS_REVIEW`，完成复核前不进入排名。

c661 的 `agent/conversation.json` 有五个维度，但其中四个显式标记为：

```text
insufficient_student_evidence_in_selected_material
```

只有“独立验证与质疑”有一个 unit。这与平台“待复核”语义直接吻合，足以解释材料为什么无法产生数值原始分。相比之下：

- 文件约 `14 KiB`，没有证据表明大小超限。
- 官方路径是 `agent/conversation.json`。
- 官方规则明确总分为无上限累加，0–100 不是该材料的本地总分上限。

这些不是本轮认定的主因，也不替代平台未公开报告。

材料声明的候选档位合计 `4.0`。这不是官方评分。每个引用不超过 240 字符，能够通过 RFC6901 pointer 定位到 JSON 内字符串并精确匹配原文；同一原文没有跨 unit 或跨维度复用。0.5 分实例不附未来计划作为结果。
