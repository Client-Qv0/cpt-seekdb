# 并行 Top-K 共享筛选上界

基线：`0d4e314dce4613c90c4c9fa8986bb44598d37a67`（日志映射＋精确 7-bit 粗筛）。候选只启用在并行、升序 TopK-10 的整数粗筛。每个切片仍独立维护堆；只有堆中已有 K 个合格行时才能发布上界。其他切片每批读一次较紧的整数界，仍用严格大于判断，FP64 精算、并列主键和过滤逻辑不变。读到旧值只会多保留候选。

## 结果与取舍

本机 WSL2/ext4、独立数据库 cgroup、2 CPU / 2 GiB / 零 swap，10k×128、100 批持久写、1000 次正式 JSONL 查询，过滤占一半。20 轮 A/A′/B，以同轮两份控制时长的几何平均作对照。负号代表耗时下降。

| 指标 | 配对中位差 | 95% 描述区间 |
|---|---:|---:|
| 混合查询 | −7.88% | −8.71% 至 −7.50% |
| 有过滤 | −6.11% | −6.53% 至 −5.42% |
| 无过滤 | −9.49% | −10.21% 至 −9.01% |
| 写入 | +0.62% | −0.97% 至 +1.73% |

混合查询 20/20 胜，峰值内存相对 7-bit 基线中位差 0 MiB，物理写入每轮 6,049,792 B，未观测到候选新增物理读取。每轮映射确实命中；完整有序 JSONL 回包逐字节一致。

独立诊断构建统计 3 个种子各 1000 条正式形状查询的精算访问：282,120→246,961、283,244→249,113、284,395→249,740。总数减少 12.05%–12.46%；分项过滤减少 9.44%–10.05%，无过滤减少 13.98%–14.28%。诊断在 2 个 CPU 上跟踪真实路径，统计其操作次数；诊断构建耗时不参与上述配对。

Release CTest 9/9，压力 21/21，优化 17/17，858 条差分和独立参考检查，正式管道协议检查，以及公开 20 例本地适配通过。128 MiB 零 swap 下独立核对映射、过滤/等距、逐位参考、checkpoint 换代与 SIGKILL 恢复，无 OOM。
