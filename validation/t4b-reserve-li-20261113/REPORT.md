# T4b — vector_literal / pack_row 受限预分配（结论：不并入）

基线：T3 提交。改动：`vector_literal` 按 `min(dim, 文本长度/2+1)` 预留；
`pack_row` 先算精确字节数再 `reserve`。

- 不信任 schema 维度做预留：恶意 `CREATE TABLE VECTOR(4000000000)` 不会触发 4 GB 预留。
- `pack_row` 预留值是精确字节和，不会超分配。

## 实测（2 CPU cgroup，1000 次查询，12 对）

| 指标 | 配对中位 | 胜率 |
| --- | ---: | ---: |
| 写入耗时 | +1.35% | 8/12 |
| 查询耗时 | +0.26% | 7/12 |

## 结论

处于噪声内（同二进制对照中位 ±3%），**没有稳定净收益**。按门槛**不并入集成分支**，
保留本分支与原始数据。若日后写入占比变化可重新评估。
