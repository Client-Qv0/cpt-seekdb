## 为什么是重大突破

c661 的五个评价维度中，只有“独立验证与质疑”有一个 unit，另外四个维度显式标成 `insufficient_student_evidence_in_selected_material`。按照官方 v3 规则，任一维度证据不足会进入 `NEEDS_REVIEW`，原始分保持 `null`。

d21e 为五个维度分别建立了独立、可定位、原文可匹配的证据实例，并把学生证据与执行结果分开引用。官方现在已输出有效原始分 `3.000000`，确认此前的无效结果可以被材料修复解决。

## 与 c661 对照

两版生产输入相同，因此官方性能 E 的差异不归因于 d21e 的 Agent 材料修复；它属于正式运行之间的测量波动或平台环境差异。本记录不把本地配对结果与不同的官方运行拼接。

## 边界

- 截图展示的是 Agent Prompt 原始评价分，不是 40 分制排名得分。
- 截图没有展示当前排名、评审报告、性能 I/O 和内存子指标。
- 官方成绩绑定 d21e；之后新增的证据提交不会自动继承该成绩。
- 本记录不触发正式评测。

## 后续方向

1. 保留 d21e 作为首个 Agent Prompt 有效版本，不再改写其 `agent/conversation.json`。
2. 性能优化应从未改生产代码的 `d21e` 或后续独立分支继续，分别绑定每次官方结果。
3. Agent 材料还有从 `3.000000` 向上改进的空间，但后续材料变更必须使用新材料版本单独提测，不能覆盖 d21e 证据。
