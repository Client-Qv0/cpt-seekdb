# 日志映射精确视图：生产接入验证

以 `f9a61047` 为性能基线，原型记录见 `validation/slim-journal-view-20261116/`。这版默认给预算内、至少 4,096 行、128 维、当前查询可用量化筛选的已提交视图启用只读日志映射。粗筛和排序语义不变，逐维 FP64 精算读取原始日志，避免持有完整 FP32 副本。日志最大映射长度 16 MiB。显式事务、降序查询、码域不匹配、映射不可用等情况走原有路径。事务、写入或关闭前释放旧映射，checkpoint 后重新从当前日志建视图。数据格式、持久化约定、协议及 Agent 材料不变。

## 本机性能验收

WSL2、ext4、数据库独立 cgroup、2 CPU、2 GiB、零 swap，驱动独立绑核。10,000×128、100 批自动提交、10 条预热、1,000 条正式 JSONL 查询，等值过滤占一半，种子 3179、3181、3187。20 轮交错测试：每轮两份基线加一份候选，所有候选在计时前通过 `/proc/PID/maps` 验证确实启用只读日志映射。耗时以同轮两份基线的几何平均作对照。

| 指标 | 候选中位差 | 描述性 95% 区间 |
|---|---:|---:|
| 混合查询耗时 | **−5.48%** | −8.20% 到 +0.02% |
| 过滤查询耗时 | −4.98% | −7.94% 到 +1.60% |
| 无过滤查询耗时 | −5.37% | −8.68% 到 −0.19% |
| 写入耗时 | −0.30% | −2.21% 到 +1.51% |
| 峰值内存（对主基线） | **−4.75 MiB** | −4.93 到 −4.75 MiB |

混合查询通过 **中位降幅至少 3%** 的保留门槛。14/20 轮获胜，区间仍接近 0%，不能断言真实提速幅度至少 3%。同二进制 A/A 混合查询中位差 +0.25%，IQR 22.74 个百分点；本地数据不外推为官方 E。内存 20/20 轮下降。捕获的目标设备物理写入每进程相同，为 6,049,792 B；映射组未观察到额外物理读。20 轮完整有序 JSONL 回包摘要一致。
