# Q7 幸存掩码与收集：实验结论

基线为远端共享 Top-K 上界版 `04644529b5ff8d3c153c5c1f19b9b238e50a4e8d`，和本地已验证的 `586516a5` 文件树一致。判据：混合正式 JSONL 查询中位至少快 3%，回包完全一致，无可辨别的内存和 I/O 回归。

本实验让 8 行整数粗筛在 AVX2 寄存器里一起做点积归约、范数修正和阈值比较，直接返回 8 位掩码。相同的点积累加、量化界和 FP64 精算不变；非 32 对齐维度沿用原整数距离。收集按从低到高的置位遍历，保留原来的行顺序。等于阈值的行必须留下。

## 诊断与验收结果

- 3 个种子各 1,000 条查询的轻量抽样：约 743,000 个 8 行粗筛组，约 186,500 次掩码收集。两线程耗时相加、按 17 ns 时钟读差粗略扣减后，点积和旧归约约 26.7–28.4 ms，整数比较生成掩码约 2.7–3.7 ms，收集约 4.9–5.2 ms。只能用来估算相对工作量，不能视为端到端可节省的墙钟；采样构建的结果与正式基线逐项相同。
- 候选 Release CTest 9/9。整数掩码单测覆盖 17、32、128、8192 维、乱序候选、分数等于阈值、半整数和无穷阈值。
- 两轮各 20 组 A/A′/B。10k×128、100 次持久批写、1,000 条正式 JSONL TopK-10（半数等值过滤），2 CPU/2 GiB/零 swap，WSL2/ext4。以同轮两份控制的几何平均作对照；确认轮另带旧比赛基线测内存。
- 首轮混合中位 −3.40%（95% 描述区间 −5.59% 至 −1.67%，17/20 胜），过滤 −3.29%，无过滤 −3.86%。确认轮混合中位 −1.60%（−4.57% 至 −0.75%，16/20 胜），过滤 −1.21%，无过滤 −2.27%。40 对合并中位 −2.22%，仅作描述，不替代两轮判据。
- 40 组完整有序回包摘要一致，每轮实测映射命中和 1,009 次偏置粗筛。候选的峰值内存中位差 0 MiB，物理写入 6,049,792 B，候选没有物理读取。确认轮对旧比赛基线保留 4.75 MiB 的中位内存降幅。

**决定：不保留。** 效果倾向为正，但是没有复现 3% 的保留门槛。源码和测试退回共享上界版。工作区的 `outputs/q7-survivor-mask-20261116/` 保留完整逐轮数据、诊断脚本和可审阅的候选补丁。未推送、未改 Prompt、未合并比赛分支。
